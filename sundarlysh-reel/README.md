# Sundarlysh Events – Wedding Moodboard Reel

`sundarlysh_moodboard_reel.mp4`: 720x1280, 30 fps, 9.9 s vertical reel (Instagram Reels / Stories).

- 0–7.5 s: fast photo cuts (every 3–4 frames) behind a paper note card; the text "This is your sign / to share your / Wedding Moodboard / with Us" appears word by word on the beat (1.0, 1.8, 2.6, 3.4, 4.2, 5.0 s).
- 7.5–9.9 s: Sundarlysh Events logo end card.
- Audio: the background track from the reference reel, copied unchanged.

## Re-rendering

`render.py <workdir> <image_dir> <out.mp4> <logo.jpg>` expects `<workdir>/assets/music.m4a` and `<workdir>/assets/fonts/Italiana-Regular.ttf.ttf` ([Italiana](https://fonts.google.com/specimen/Italiana), OFL). Set `FIRST=<photo id>` to choose the opening shot. Needs Python 3 with Pillow and NumPy, plus ffmpeg.
